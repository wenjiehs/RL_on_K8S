## 快速开始

### 1. 启动服务

#### 启动后端
```bash
# 设置 KUBECONFIG
export KUBECONFIG="$HOME/.kube/config:$HOME/Downloads/cls-jrnaysd3-config"

# 启动后端服务
cd RL_on_K8S
./bin/api-server
```

#### 启动前端
```bash
cd frontend
npm run dev
```

### 2. 访问应用

打开浏览器访问：`http://localhost:5173`

## 集群管理

### 连接到 Kubernetes 集群

1. **查看可用 Context**
   - 点击顶部导航栏的"集群管理"
   - 系统会自动列出所有可用的 Kubernetes Context

2. **选择并连接**
   - 从下拉列表中选择目标 Context
   - 点击"连接"按钮
   - 等待连接成功提示

3. **验证连接**
   - 连接成功后，页面会显示集群信息
   - 包括集群名称、节点数量、Pod 数量等

### 切换 Namespace

1. 在页面顶部找到 Namespace 选择器
2. 从下拉列表中选择目标 Namespace
3. 页面会自动刷新并显示该 Namespace 下的资源

## 环境管理

### 创建 Ray 环境

#### 基本配置

1. **进入环境管理页面**
   - 点击左侧导航栏的"环境管理"

2. **点击创建按钮**
   - 点击页面右上角的"创建环境"按钮

3. **填写基本信息**
   ```
   环境名称: my-ray-cluster
   框架类型: Ray
   Namespace: default
   ```

4. **配置 Head 节点**
   ```
   CPU: 2 核
   内存: 4Gi
   GPU: 0（可选）
   镜像: rayproject/ray:2.9.0
   ```

5. **配置 Worker 节点**
   ```
   副本数: 2
   CPU: 2 核
   内存: 4Gi
   GPU: 0（可选）
   镜像: rayproject/ray:2.9.0
   ```

6. **存储配置**
   - 系统会自动检测 CFS 存储状态
   - 绿色提示表示存储就绪
   - 黄色警告表示需要初始化（勾选"自动初始化"）

7. **创建环境**
   - 检查所有配置
   - 点击"创建"按钮
   - 等待环境创建完成

#### 高级配置

**自定义镜像**
```yaml
镜像仓库: your-registry.com
镜像名称: custom-ray
标签: latest
```

**资源限制**
```yaml
CPU 限制: 4 核
内存限制: 8Gi
GPU 限制: 1
```

**环境变量**
```yaml
RAY_BACKEND_LOG_LEVEL: debug
PYTHONUNBUFFERED: 1
```

### 管理环境

#### 查看环境列表

环境列表显示以下信息：
- 环境名称
- 框架类型
- 状态（Running/Pending/Failed）
- Head 节点配置
- Worker 节点数量
- 创建时间
- 操作按钮

#### 查看环境详情

1. 点击环境名称或"详情"按钮
2. 查看详细配置信息：
   - 基本信息
   - 资源配置
   - Pod 列表
   - 事件日志
   - 存储挂载信息

#### 扩缩容

1. 在环境列表中找到目标环境
2. 点击"扩缩容"按钮
3. 调整 Worker 节点数量
4. 点击"确认"

#### 删除环境

1. 在环境列表中找到目标环境
2. 点击"删除"按钮
3. 确认删除操作
4. 等待删除完成

### 访问 Ray Dashboard

1. 在环境列表中找到目标环境
2. 点击"Dashboard"按钮
3. 系统会自动打开新标签页访问 Ray Dashboard
4. 在 Dashboard 中可以：
   - 查看集群状态
   - 监控任务执行
   - 查看资源使用情况
   - 调试 Ray 应用

## 数据管理

### 数据集概览

#### 查看数据集列表

1. 进入"数据管理"页面
2. 切换到"Datasets"标签页
3. 查看所有可用数据集

数据集信息包括：
- 实验 ID
- 数据类型（raw/train/eval/model）
- 存储路径
- 文件大小
- 文件数量
- 创建时间
- 状态

#### 数据类型说明

- **raw**: 原始数据（橙色标识）
- **train**: 训练数据（蓝色标识）
- **eval**: 评估数据（绿色标识）
- **model**: 模型文件（紫色标识）

### 创建数据集

#### 方法一：通过界面上传

1. 点击"创建数据集"按钮
2. 填写信息：
   ```
   实验 ID: exp001
   数据类型: raw
   日期: 2025-11-17（自动填充）
   ```
3. 选择文件上传
4. 等待上传完成

#### 方法二：直接写入 CFS

```bash
# 通过 kubectl 访问 CFS
kubectl exec -n default cfs-data-accessor -- sh

# 创建目录
mkdir -p /cfs/rl-data/exp001/raw/2025-11-17

# 上传文件（示例）
cat > /cfs/rl-data/exp001/raw/2025-11-17/data.txt << EOF
Sample data content
EOF
```

### 文件浏览器

#### 浏览文件

1. 切换到"File Browser"标签页
2. 使用左侧导航面板快速跳转
3. 在右侧文件列表中浏览文件

#### 切换视图

- **列表视图**: 显示详细信息（名称、大小、修改时间）
- **网格视图**: 以卡片形式显示（适合浏览图片）

点击右上角的视图切换按钮进行切换。

#### 文件操作

**下载文件**
1. 找到目标文件
2. 点击"下载"按钮
3. 文件会自动下载到本地

**删除文件**
1. 找到目标文件
2. 点击"删除"按钮
3. 确认删除操作

**预览文件**
1. 找到目标文件
2. 点击"预览"按钮
3. 在弹出窗口中查看内容

### 文件预览

#### 文本文件预览

支持的格式：
- `.txt` - 纯文本
- `.log` - 日志文件
- `.json` - JSON 格式
- `.yaml` / `.yml` - YAML 配置
- `.md` - Markdown 文档
- `.py` - Python 代码
- `.sh` - Shell 脚本
- `.csv` - CSV 数据

预览功能：
- 语法高亮
- 行号显示
- 代码折叠
- 搜索功能

#### 图片文件预览

支持的格式：
- `.jpg` / `.jpeg`
- `.png`
- `.gif`
- `.bmp`
- `.webp`

预览功能：
- 原图显示
- 缩放控制
- 下载原图

#### Parquet 文件预览

1. **打开预览**
   - 找到 `.parquet` 文件
   - 点击"预览"按钮

2. **查看 Schema**
   - 列名
   - 数据类型
   - 是否可为空

3. **浏览数据**
   - 表格形式展示
   - 默认显示前 100 行
   - 支持分页浏览
   - 空值显示为 `null`

4. **导出数据**
   - 点击"下载"按钮
   - 下载完整 Parquet 文件

### 存储统计

#### 查看统计信息

1. 切换到"Storage Stats"标签页
2. 查看以下统计：
   - **总存储占用**: 所有数据集的总大小
   - **数据类型分布**: 各类型数据的占比
   - **文件数量**: 总文件数和各类型文件数
   - **实验统计**: 各实验的数据量

#### 图表说明

- **饼图**: 数据类型分布
- **柱状图**: 各实验数据量对比
- **趋势图**: 存储增长趋势（如果有历史数据）

## Web 终端

### 连接终端

1. **打开终端**
   - 在环境列表中找到目标环境
   - 点击"终端"按钮
   - 终端会在新窗口中打开

2. **终端功能**
   - 完整的 Shell 交互
   - 支持所有 Linux 命令
   - 自动调整窗口大小
   - 支持复制粘贴

### 常用操作

#### 查看 Ray 状态
```bash
ray status
```

#### 运行 Python 脚本
```bash
python /cfs/rl-data/exp001/train/script.py
```

#### 查看日志
```bash
tail -f /tmp/ray/session_latest/logs/raylet.out
```

#### 访问 CFS 存储
```bash
ls -la /cfs/rl-data
cd /cfs/rl-data/exp001
```

### 终端快捷键

- `Ctrl + C`: 中断当前命令
- `Ctrl + D`: 退出终端
- `Ctrl + L`: 清屏
- `Ctrl + R`: 搜索历史命令
- `Tab`: 自动补全

## 最佳实践

### 环境管理

1. **命名规范**
   - 使用小写字母和连字符
   - 包含项目名称和用途
   - 示例：`project-ray-training`

2. **资源配置**
   - 根据实际需求配置资源
   - 避免过度分配
   - 使用资源限制防止资源耗尽

3. **镜像选择**
   - 使用官方镜像或经过验证的镜像
   - 固定镜像版本，避免使用 `latest`
   - 定期更新镜像以获取安全补丁

### 数据管理

1. **目录结构**
   - 遵循三级目录结构
   - 使用有意义的实验 ID
   - 按日期组织数据

2. **文件命名**
   - 使用描述性文件名
   - 包含版本信息
   - 避免特殊字符

3. **数据清理**
   - 定期清理过期数据
   - 归档重要数据
   - 监控存储使用情况

### 性能优化

1. **Parquet 文件**
   - 使用合适的压缩算法（推荐 snappy）
   - 控制文件大小（建议 < 100MB）
   - 使用列式存储优化查询

2. **并发控制**
   - 避免同时创建大量环境
   - 限制并发文件上传数量
   - 使用队列管理批量操作

3. **网络优化**
   - 使用内网访问 CFS 存储
   - 启用 HTTP/2 加速传输
   - 压缩大文件传输

### 安全建议

1. **访问控制**
   - 使用 RBAC 控制权限
   - 定期审查访问日志
   - 限制敏感操作权限

2. **数据安全**
   - 加密敏感数据
   - 定期备份重要数据
   - 使用版本控制

3. **网络安全**
   - 使用 HTTPS 访问
   - 配置防火墙规则
   - 启用网络策略

## 故障排查

### 常见问题

#### 环境创建失败

**症状**: 环境状态显示 Failed

**排查步骤**:
1. 查看环境详情中的事件日志
2. 检查资源配额是否充足
3. 验证镜像是否可访问
4. 查看 Pod 日志

#### 文件上传失败

**症状**: 上传进度卡住或报错

**排查步骤**:
1. 检查文件大小是否超限
2. 验证网络连接
3. 查看后端日志
4. 检查 CFS 存储空间

#### 终端连接失败

**症状**: 终端显示连接错误

**排查步骤**:
1. 确认 Pod 正在运行
2. 检查网络连接
3. 验证 WebSocket 支持
4. 查看浏览器控制台错误
